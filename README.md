* **Developed by:** Thomas
* **Developed for:** Maria
* **Team:** Verlhac
* **Date:** November 2024
* **Software:** MATLAB R2024b

## Input description

XLS spreadsheets generated by *Trackmate* Fiji plugin 

## Script description

* Calculate the Mean Squared Displacement (MSD) and velocity autocorrelation (VCorr) for each particle
* Produces five files per input spreadsheet:
  * 2 CSV spreadsheets containing MSD and VCorr data.
  * 3 PNG images representing: particle's displacement in the XY plane, MSD plot, and VCorr plot.

## Dependencies

*MSD analyzer* MATLAB add-on
